# Hospital Management System

A simple hospital management system scaffold built with Node.js, Express, and EJS.

## Features
- Dashboard view
- Static assets for styling and scripts
- Starter SQL schema
- Basic Express server setup

## Getting started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Open http://localhost:3000
